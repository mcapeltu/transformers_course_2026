How to Run the Solution Notebook

Practical advice for local Jupyter and Google Colab deployment.

HomeCourse BlockMini-Project

What is included in the notebook

The solution notebook is organized as a complete end-to-end pipeline: configuration, corpus loading, vocabulary extraction, tokenization, train/validation split, batch generation, Transformer components, full model definition, loss estimation, training loop, text generation, and causal-attention inspection.

Local execution

  1. Install Python 3.10 or newer.
  2. Install Jupyter and PyTorch:
pip install jupyter torch
  1. Place the notebook in a working folder.
  2. Optionally add an input.txt file with your corpus.
  3. Start Jupyter:
jupyter notebook
  1. Open mini_project_solution_transformer.ipynb.
  2. Run all cells in order.

Google Colab execution

  1. Upload the notebook to Google Colab.
  2. If desired, upload an input.txt file to the runtime working directory.
  3. Run all cells in order.
  4. If a GPU is needed, enable it in Runtime → Change runtime type → GPU.

Important notebook behavior

Corpus source
If input.txt exists, the notebook reads it. Otherwise it falls back to a built-in repeated text sample.
Framework
PyTorch
Model type
Character-level autoregressive Transformer
Training objective
Next-character prediction with cross-entropy loss
Generation
Autoregressive sampling with a configurable temperature
Inspection
Attention matrices can be extracted to verify causal masking

Practical advice

  • Run the notebook in order. The later cells depend on earlier definitions.
  • Check tensor shapes if anything fails. Most attention bugs are shape bugs.
  • If training seems too slow, reduce max_iters, n_embd, or n_layer.
  • If the generated text is too repetitive or too chaotic, adjust the generation temperature.
  • To make the task more meaningful, replace the fallback corpus with a richer input.txt.
