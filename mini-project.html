Implementing an Autoregressive Transformer for Character-Level Text Generation (ATChar-LTG)

HomeCourse BlockRun the Notebook

General description

In this mini-project, students implement a Transformer model at the character level to generate text by predicting the next character in a sequence. The model is trained with an autoregressive objective, so it learns to predict the next character from the previous context only.

The assignment focuses on the scaled dot-product self-attention mechanism discussed in the lectures and on building a complete minimal Transformer pipeline in PyTorch.

Core components to implement

  • Token encoding and decoding
  • Token and positional embeddings
  • One masked self-attention head with Q, K, V, and causal masking
  • Multi-head attention
  • Transformer block with attention and feed-forward network
  • Training loop with optimizer and backpropagation
  • Autoregressive text generation
  • Optional inspection of attention weights

Implementation pipeline

encode(text)
→ tensor of token IDs
→ embeddings
→ sequence of vectors
→ self-attention / Transformer blocks
→ linear layer
→ logits
→ predicted next token

What students should understand by the end

  • How a corpus becomes token IDs and then vectors.
  • Why positional embeddings are needed.
  • How the causal mask prevents information leakage from future tokens.
  • How multi-head attention enriches the representation.
  • How logits, cross-entropy, and gradient descent fit into the training loop.
  • How autoregressive generation works one token at a time.
